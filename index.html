Editar a página

Mude os campos e toque em Ver na página. Para valer para todo mundo, copie o código e cole no GitHub (instruções no final).

Como publicar: no GitHub, abra o index.html, toque no lápis, procure o bloco entre CONFIG-INICIO e CONFIG-FIM, troque pelo código copiado e toque em Commit changes. Em 1 a 3 minutos o site atualiza para todos.
